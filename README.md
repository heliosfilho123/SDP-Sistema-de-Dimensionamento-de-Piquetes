# SDP — Sistema de Dimensionamento de Piquetes

**Desenvolvido em Python**

## Sobre o projeto

O SDP é um sistema computacional desenvolvido para auxiliar o planejamento e o dimensionamento de piquetes destinados à bovinocultura leiteira.

O projeto tem como referência inicial as condições de produção do Cerrado brasileiro, considerando sistemas de pastejo irrigados e de sequeiro.

## Objetivos
- Auxiliar no planejamento de sistemas de piquetes.
- Organizar informações sobre rebanho e alimentação.
- Reunir parâmetros técnicos de forrageiras.
- Apoiar a tomada de decisão na propriedade rural.

## Tecnologias
- Python
- Banco de dados técnico de forrageiras
- PyInstaller (distribuição executável)
